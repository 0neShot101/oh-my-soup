Wait only when blocked with nothing else to do.
Blocks on background jobs/services you started, or on a direct reply owed from a message you sent this run; returns on the first result, message, or steering interrupt. Message-only waits use progressively longer windows; a safety cap returns current state.
Nothing you started running and no reply owed? Returns immediately. A reply blocked on your own result names that dependency; do independent work, send the needed message, or finish without the answer.
Results and messages auto-deliver. NEVER poll while work remains.
