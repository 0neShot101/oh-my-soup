Open, list, and close SSH sessions with retained credentials. `bash target: "<name>"` runs there; `/ssh:<name>:/path` and `ssh://<name>/path` read, write, and grep. TRAMP `/ssh:[user@]host[#port]:path` also connects lazily to configured hosts or OpenSSH destinations; `bash cwd` selects remote execution. Only single-hop SSH; TRAMP filenames are literal, and empty/relative/`~/` paths start at remote home.

- `connect`: `host` is `[user@]host[:port]`, an address, DNS name, or `~/.ssh/config` alias; `user`/`port` fill in parts the destination lacks (a conflicting value is an error); `name` is the target name (default `user@host[:port]`). Auth: `password` (password or keyboard-interactive login), `key` (local private key path, `~` expands), or neither (agent / default keys). The password stays in this process's memory; it is never written to disk or placed on a command line. `connect` authenticates once and reports the remote OS and shell; reconnecting the same name refreshes its credentials.
- `forward`: open local (`-L`), remote (`-R`), or dynamic SOCKS (`-D`) port tunnels on `name` (or `connect` with `forward` / `local_port` + `remote_port`). Pass `forward: "8080:127.0.0.1:80"` (or `["L:8080:localhost:80", "R:9000:localhost:3000", "D:1080"]`) or `forward_type` (`"local" | "remote" | "dynamic"`), `local_port`, `local_host`, `remote_port`, `remote_host`.
- `unforward`: close specific port forward(s) on `name` (or omit `forward`/`local_port` to stop all active forwards on `name`).
- `disconnect`: close the session named `name`, stop its port forwards, and forget its credentials.
- `list`: open sessions and configured hosts with address, auth kind, probed OS/shell, and active port forwards.
- POSIX commands retain shell state per owner and authenticated destination; calls serialize. Explicit `cwd` changes directory; omission retains it. Disconnect, credential replacement, timeout, abort, or owner disposal closes the shell; later calls reconnect without replay. Native cmd/PowerShell commands remain one-shot.

Rules: never guess credentials — use what the user supplied, or ask. Prefer a key or agent when one exists; a password is for hosts that only accept password login. Keep sessions open while a task needs them and disconnect when finished. Windows hosts run commands under cmd/PowerShell unless a POSIX compat shell is found (`compat`, default on); `ssh://` transfers need a POSIX remote.
